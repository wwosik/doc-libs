# Harbour handbook

How the planner runs, for the people who run it

## Daily run

The run starts at six and ends when every schedule is calculated.

::: pagebreak
## Incidents

A failed run is restarted once; a second failure pages the duty engineer.
:::

> [!WARNING]
> Do not restart a run by hand while the queue still holds its work.
>
> - Check the queue first.
> - Then restart.
