# E08 Document converters

> Status: in progress

## Goal

The converters to Markdown keep more of the source document: tables, lists, code and images in place from PDF, speaker notes from PPTX.

## Why

Markdown converted from a document is what an AI agent reads; what the converter loses, the agent never sees.
