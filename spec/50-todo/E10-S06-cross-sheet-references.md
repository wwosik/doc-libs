# E10-S06 Cross-sheet references in formulas

> Status: todo
> Epic: [E10 Workbook generator](E10-workbook-generator.md)

## Summary

Formulas can refer to a column on another sheet, `[Sheet!Header]`, as a whole column range, for
lookups such as `XLOOKUP([Customer], [Customers!Name], [Customers!Region])`.

## Context

E10-S02 allows only references within the same row (`[Header]`), `{row}` and A1 references. This
story is to be planned once E10-S02 is in place.
